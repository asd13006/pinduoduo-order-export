# 拼多多買家訂單匯出（增強版）

一個 **Tampermonkey 使用者腳本**，喺拼多多網頁版自動抓取你嘅買家訂單，支援自動載入全部訂單、日期範圍篩選、自選匯出欄位，一鍵匯出 **Excel (.xlsx)** / **CSV**。

呢個係參考 [zodiac1111/Pinduoduo-buyer-order-export](https://github.com/zodiac1111/Pinduoduo-buyer-order-export) 而做嘅升級版，解決咗原 project 嘅主要痛點（見下方「點解更好」）。

---

## 同原 project 嘅分別（點解更好）

| | 原 project | 呢個版本 |
|---|---|---|
| 抓資料方式 | 手動喺 Chrome DevTools 設斷點 | **自動攔截 XHR / fetch API**，唔使設斷點 |
| 載入全部訂單 | 人手用 Space 鍵慢慢滾 | **「自動載入全部」按鈕**，自動滾到冇新訂單為止 |
| 依賴內部變數名 | 依賴 `this.itemsStore` 呢類 React 內部變數（改版就壞） | 唔依賴變數名，直接睇 API 回傳內容 |
| 匯出格式 | 控制台貼文字，自己另存 | **一鍵匯出 Excel / CSV**，Excel 含「統計總覽」分頁 |
| 篩選 | 冇 | **日期範圍** + **關鍵字** + **自選匯出欄位** |

## 需求

- Chrome 或 Edge 瀏覽器（或任何支援 Tampermonkey 嘅瀏覽器）
- 安裝 [Tampermonkey](https://www.tampermonkey.net/) 擴充功能

---

## 安裝步驟

1. 喺 Chrome / Edge 安裝 **Tampermonkey** 擴充功能。
2. 打開 Tampermonkey 選單 → **「新增腳本」**（Create a new script）。
3. 將檔案 [`pdd-order-export.user.js`](./pdd-order-export.user.js) 嘅內容全部貼入去，取代原本嘅範例代碼。
4. 按 **Ctrl+S** 儲存。

或者更簡單：Tampermonkey 支援直接匯入 `.user.js` 檔案——係喺 Tampermonkey dashboard 選 **「實用工具」→「匯入」**（或直接將檔案由檔案總管拖入瀏覽器），Tampermonkey 會自動彈出安裝畫面。

> 留意：腳本只會對 [`mobile.pinduoduo.com`](https://mobile.pinduoduo.com/) 同 `mobile.yangkeduo.com` 生效。

---

## 使用步驟

1. 用瀏覽器打開 <https://mobile.yangkeduo.com/>（或者 `mobile.pinduoduo.com`）並**登入**（手機號碼 + 驗證碼）。
2. 進入**「我的訂單」→「查看全部」**訂單列表頁面。
3. 右下角會出現紅色 **「訂單」** 浮動按鈕，按下打開面板。
4. 揀日期範圍（`從` / `到`）。
5. 撳 **「搜尋 & 匯出 Excel」**：腳本會自動載入全部訂單、按日期範圍過濾，然後直接匯出 Excel。

## 功能細節

### 一鍵搜尋 & 匯出
- 撳「搜尋 & 匯出 Excel」之後，程式會自動：
  1. 向下滾動，載入訂單 —— **三條路一齊捉**：網頁 `order_list_v4` API 攔截、React 內部狀態掃描、以及**訂單卡片 DOM**（`data-order-sn`）。因為拼多多首屏訂單好多時係直接嵌喺頁面、唔經 XHR，所以一定要讀 DOM 先捉得齊。全部非阻塞，**唔會卡**。
  2. **預設會一直載到列表底部**（確保唔漏單）。如果你想快啲，可以勾選「只載到日期下限就停（快，但可能漏單）」。
  3. 一次過匯出 Excel（含「訂單明細」+「統計總覽」分頁）。
- 面板會即時顯示「已取得 N 筆 / 合計 / **日期 xxx ~ xxx**」；個日期範圍就係實際捉到嘅區間，可以用嚟確認有冇載齊。
- 想中途停可以撳「停止」。

### 日期範圍
- 兩個日期輸入框（`從` / `到`），只匯出喺範圍內落單嘅訂單（含起訖日）。唔揀範圍就匯出全部。
- 如果想穩陣啲（怕漏單），可以**唔揀日期**先撳一次載入全部，再揀日期匯出。

### 匯出欄位（可選）
- 面板上有「選擇匯出欄位（已選 11 項）▾」，**預設收埋**。撳開後可以勾選想匯出嘅欄位：
  `下單時間`、`訂單號`、`商品名稱`、`規格`、`單價`、`數量`、`實付金額`、`店鋪`、`狀態`、`類型`、`購買連結`
- 有「全選 / 全不選」快捷掣；唔撳開就用晒全部欄位。

### 記住選項
- 你揀過嘅**匯出欄位**會自動記得（Tampermonkey 持久儲存），**下次打開自動載入返**，唔使再 tick。
- **日期範圍唔記**：每次重新打開都係空白，你另揀。
- 用 Tampermonkey 儲存（`GM_setValue`），後備用頁面 `localStorage`；清除瀏覽器資料先會冇。

### 多語言
- 支援**繁體中文（預設）／簡體中文／英文**，根據**你瀏覽器嘅語言**自動預設。
  - `zh-CN`/`zh-Hans` → 簡體中文；`zh-TW`/`zh-HK`/其他中文 → 繁體中文；`en-*` → 英文。
- 面板右上角有語言選擇（繁體／简体／EN），揀完會記住；所有介面、狀態、欄位、Excel 標題都會即時切換。

### 暗黑模式 & 動效
- 面板右上角有 **🌙/☀️ 掣**切換**暗黑模式**（預設跟系統）；揀過嘅主題會記住。
- 面板開合、按鈕 hover／撳、欄位開合、日期輸入框 focus、checkbox 都有**順滑嘅過渡動效**（主要用 `transform`/`opacity`，唔會卡）。

### 搜尋期間可停止
- 撳「搜尋 & 匯出 Excel」後，個掣會變成橙色「**⏹ 停止搜尋**」；想停隨時撳，會即刻停止載入（唔會匯出），狀態會話你「已停止」。

### 價格單位
- **自動由「分」換算做「元」**，你可以直接攞到正確嘅價錢，**唔使理「分」**。

> 資料抓取同欄位結構係參考「多多開」擴充功能（拼多多買家個人訂單匯出）去校準嘅：訂單用 `order_sn`、`order_status_prompt`、`order_amount`、`order_goods[].goods_*`、`mall.mall_name`。

### 匯出 Excel (.xlsx)
- **「訂單明細」**分頁：每筆訂單一行。
- **「統計總覽」**分頁：總筆數、合計金額、**按店鋪**統計、**按狀態**統計。
- Excel 用 [SheetJS](https://sheetjs.com/) 由 CDN 載入；若離線或連唔到 CDN，會自動改為匯出 CSV。

## 疑難排解

- **撳「搜尋」冇反應／冇抓到資料**：請確保你已登入，且而家喺訂單列表頁。腳本會自動讀取網頁已載入嘅訂單；如果仲係冇，試下重新整理頁面再撳。面板會顯示「已取得 X 筆訂單」，用嚟確認有冇捉到。
- **「搵到 0 筆」**：可能係日期範圍內真係冇訂單，或者仲未載入晒。試下放寬日期範圍（或唔揀日期），再撳一次。
- **金額/$ 比例怪**：正常情況程式會自動由「分」換算做「元」。若仍然怪，話我聽，我睇下 `dump()`。
- **匯出少咗訂單（例如指定 8/12~9/11 但只出到 8/30）**：
  1. 睇面板右邊嘅 **「日期 xxx ~ xxx」**，呢個係實際已載入嘅區間。
  2. 確認你喺訂單頁係揀「**全部**」分頁、冇加狀態篩選。
  3. 試下**唔揀日期**直接撳搜尋，睇個「日期 ~」會唔會伸延到你預期嘅日期。如果會 → 之前係「提早停」造成；如果唔會 → 該列表本身最新就係嗰個日期。
  4. 仲有問題就開 console 打我哋嘅診斷：
     ```js
     __pddOrderExport.diag()
     ```
     將印出嚟嘅嘢貼返畀我（會包含：已捕捉日期範圍、各種 selector 命中數、第一張卡嘅真實 attribute/dataset、以及滾動狀態）。
- **Excel 載入失敗**：檢查網絡能否連到 `cdn.jsdelivr.net`；否則會改用 CSV。

### 想開 debug 睇細節（進階）
喺拼多多網頁 console（F12 → Console）打：

```js
__pddOrderExport.diag()     // ★ 一次過睇晒診斷資訊（最有用）
__pddOrderExport.stats()    // 睇 count / interceptCount / lastUrl
__pddOrderExport.samples()  // 睇被攔截嘅回應結構（url / shape / 有冇 order_sn）
__pddOrderExport.dump()     // 睇已捕捉訂單嘅真實欄位
__pddOrderExport.capturedSpan() // 已捕捉訂單嘅日期範圍
```

如果你需要我幫你對欄位或者查漏單，將 `diag()` 印出嚟嘅內容貼返畀我。

## 留意（重要）

- 呢個腳本只係讀取你**自己帳號**喺瀏覽器內已載入嘅訂單資料，並喺你本機匯出。請自行確認符合拼多多嘅使用條款及你所在地嘅法律規定。
- 腳本唔會上傳任何資料，所有匯出都喺你部機本地進行。
- 匯出嘅 Excel／CSV 包含 `購買連結`（會匯出全部欄位）；如唔需要，可匯出後自行刪除嗰欄。
